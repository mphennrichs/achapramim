Essa aplicação vai monitorar marketplaces em busca de ofertas conforme o cadastro realizado.
Somente o admin pode cadastrar novos usuários e ver as consultas realizadas.
O admin pode definir o tempo minimo e máximo entre as consultas, o tempo da consulta vai ser algo entre esses dois tempos, em minutos.
O admin pode mudar o role dos usuários entre usuário e admin.
O admin tem todas as permissÕes e acessos do usuário comum.
Cadastrar consulta: 
Deve conter valor (com um % de variação aceitável), palavras chave, lista de palavras bloqueadas, quantidade de ofertas listadas.
O sistema vai buscar e classificar as ofertas encontradas , ordenadas pela mais recente, exibi-las para o usuário com um valor de classificação. A classificaçao vai ser calculada pelo backend, baseado nas palavras chaves e valor.
O usuário deve ser capaz de cadastrar email e telefone , caso queira ser notificado quando uma oferta nova aparecer. 
Deve ser possivel silenciar as notificações e editar qualquer valor cadastral.
A oferta listada deve conter valor, link, pelo menos 1 imagem e a classificação.
